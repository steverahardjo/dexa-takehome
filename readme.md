# TAKE HOME TEST (DEXA FULLSTACK DEVELOPER)

## App Definition
This is an fullstack app as a Employee work-absention system during Work-from-Home(WFH)
with two kind of role: employee and admin. An admin should be able to add another employee,
change employee data, and view their absences.

## Stack
- Programming Language: Typescript
- Database: MySQL (latest stable release)
- Framework: NextJS
- TS Library: React

## Feature
### Employee
- Employee/admin login through password and email OTP.
- Input form of current time and date.
- Ability to scan a qr code and upload photo from employee phone.

### Admin
- Add a new employee info through input form page
- Ability to read a dashboard and see who has checked in, who don't.
- Ability to change a employee detail.
